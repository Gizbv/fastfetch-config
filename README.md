# CachyOS Configuration

Мои конфигурационные файлы и настройки для восстановления системы.

## Структура

- `fastfetch/` — конфигурация FastFetch
- `config/` — пользовательские конфигурации
- `system/` — системные настройки
- `packages.txt` — пакеты из официальных репозиториев
- `aur-packages.txt` — пакеты AUR
- `restore.sh` — скрипт восстановления системы

## Восстановление

После чистой установки CachyOS:

1. Клонировать репозиторий.
2. Проверить содержимое.
3. Запустить `restore.sh`.
4. Перезагрузить систему.
