# cachy-config

Персональные конфигурации для CachyOS.

## FastFetch
![FastFetch beta 4.0](fastfetch/Screen.png)

Текущая версия конфигурации: **beta 4.0**

Конфигурация FastFetch разделена на несколько частей:

- `fastfetch/config.jsonc` — основная конфигурация, оформление и логика вывода.
- `fastfetch/devices.conf` — названия и идентификаторы оборудования.
- `fastfetch/memory-usage.sh` — отображение использования оперативной памяти.
- `fastfetch/usage.sh` — отображение использования дисков и других динамических показателей.

### Функционал

Добавлено к стандартному выводу FastFetch:

- двухколоночный интерфейс с логотипом Chafa;
- проверка и отображение обновлений;
- автоматическое определение разрешения и частоты обновления мониторов;
- определение основного монитора;
- отображение запущенных виртуальных машин VirtualBox;
- определение активных наушников, колонок и микрофона через PipeWire;
- отображение материнской платы;
- отображение использования оперативной памяти с графической полосой заполнения;
- отображение использования дисков с графической полосой заполнения;
- цветовую индикацию заполнения памяти и дисков:
  - зелёный — до 69%;
  - жёлтый — 70–89%;
  - красный — 90% и выше;
- обнаружение подключённых мыши и клавиатуры с отображением статуса `Not detected`;
- вынесение аппаратных параметров в `devices.conf` без изменения основной логики конфигурации;
- вынесение динамических индикаторов памяти и дисков в отдельные скрипты.

### Аппаратная конфигурация

Названия и идентификаторы устройств вынесены в `devices.conf`.

При замене оборудования достаточно изменить значения в этом файле. Логику `config.jsonc` менять не требуется.

В `devices.conf` хранятся:

- мониторы и их видеовыходы;
- мышь и клавиатура;
- наушники, колонки и микрофон;
- модель установленной оперативной памяти.

Динамические показатели системы в этот файл не входят.

### Установка FastFetch

Скопировать содержимое каталога `fastfetch` в:

```bash
mkdir -p ~/.config/fastfetch
cp -r fastfetch/* ~/.config/fastfetch/
```

После этого FastFetch будет использовать `config.jsonc` и автоматически подключать `devices.conf`.


### Изображение (логотип)

Основной логотип FastFetch хранится в репозитории:

`fastfetch/assets/avatar.png`

После установки его необходимо скопировать непосредственно в каталог конфигурации:

```bash
cp fastfetch/assets/avatar.png ~/.config/fastfetch/avatar.png
```
