# cachy-config

Персональные конфигурации для CachyOS.

## FastFetch

![FastFetch beta 4.1](fastfetch/Screen.png)

Текущая версия конфигурации: **beta 4.1**

Конфигурация FastFetch разделена на несколько частей:

* `fastfetch/config.jsonc` — основная конфигурация, оформление и логика вывода.
* `fastfetch/devices.conf.example` — пример файла с названиями и идентификаторами оборудования.
* `fastfetch/memory-usage.sh` — отображение использования оперативной памяти.
* `fastfetch/usage.sh` — отображение использования дисков и других динамических показателей.
* `fastfetch/running-vms.sh` — определение запущенных виртуальных машин в KVM/QEMU, VirtualBox и VMware.

### Функционал

Добавлено к стандартному выводу FastFetch:

* двухколоночный интерфейс с логотипом Chafa;
* группировка информации по тематическим разделам;
* проверка и отображение обновлений;
* автоматическое определение текущего режима и разрешения мониторов;
* отображение размера и частоты обновления мониторов из `devices.conf`;
* определение основного монитора;
* автоматическое определение запущенных виртуальных машин KVM/QEMU, VirtualBox и VMware;
* определение активных наушников, колонок и микрофона через PipeWire/WirePlumber;
* отображение материнской платы;
* отображение использования оперативной памяти с графической полосой заполнения;
* отображение использования дисков с графической полосой заполнения;
* цветовую индикацию заполнения памяти и дисков:

  * зелёный — до 69%;
  * жёлтый — 70–89%;
  * красный — 90% и выше;
* обнаружение подключённых мыши и клавиатуры с отображением статуса `Not detected`;
* вынесение аппаратных параметров в отдельный `devices.conf` без изменения основной логики конфигурации;
* вынесение динамических индикаторов памяти, дисков и виртуальных машин в отдельные скрипты.

### Аппаратная конфигурация

Названия и идентификаторы устройств хранятся в локальном файле `devices.conf`.

В репозитории находится только шаблон:

`fastfetch/devices.conf.example`

Перед использованием его необходимо скопировать в `devices.conf` и настроить под своё оборудование:

```bash
cp ~/.config/fastfetch/devices.conf.example \
   ~/.config/fastfetch/devices.conf
```

При замене оборудования достаточно изменить значения в `devices.conf`. Логику `config.jsonc` менять не требуется.

В `devices.conf` хранятся:

* мониторы и их видеовыходы;
* мышь и клавиатура;
* наушники, колонки и микрофон;
* модель установленной оперативной памяти.

Для USB-устройств используется VID:PID. Его можно посмотреть командой:

```bash
lsusb
```

Для аудиоустройств VID:PID сопоставляется с `alsa.components` через PipeWire/WirePlumber.

Файл `devices.conf` содержит локальные настройки оборудования и добавлен в `.gitignore`, поэтому он не должен попадать в репозиторий.

Динамические показатели системы в этот файл не входят.

### Установка FastFetch

Скопировать содержимое каталога `fastfetch` в:

```bash
mkdir -p ~/.config/fastfetch
cp -a fastfetch/. ~/.config/fastfetch/
```

Создать локальный файл конфигурации устройств из примера:

```bash
cp ~/.config/fastfetch/devices.conf.example \
   ~/.config/fastfetch/devices.conf
```

Затем изменить значения в соответствии со своим оборудованием:

```bash
nano ~/.config/fastfetch/devices.conf
```

После этого FastFetch будет использовать `config.jsonc` и локальный `devices.conf`.

### Изображение (логотип)

Основной логотип FastFetch хранится в репозитории:

`fastfetch/assets/avatar.png`

После установки его необходимо скопировать непосредственно в каталог конфигурации:

```bash
cp fastfetch/assets/avatar.png ~/.config/fastfetch/avatar.png
```

### Git

Основная ветка:

```text
main
```

Рабочая копия репозитория синхронизируется с Gitea. После отправки изменений в Gitea настроенное зеркало автоматически передаёт их в GitHub.

Для отправки изменений:

```bash
git add .
git commit -m "Описание изменений"
git push
```

При этом локальный `fastfetch/devices.conf` не добавляется в репозиторий благодаря `.gitignore`.
